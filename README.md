# ForgePilot — Team Beacon

ForgePilot is a VS Code AI coding-agent extension being developed for the TrueFoundry Forge-a-thon 2026–27.

## Project status
Initial repository setup. See `docs/PROJECT_CONTEXT.md` for the competition requirements and `AGENTS.md` for instructions that AI coding assistants must follow.

## Core goals
- Inline code editing
- Multi-file agent mode
- Repository context retrieval
- Hunk-level diff review and safe application
- Streaming and cancellation
- Resilient TrueForge integration
